# Private Endpoints - node101

node101 provides paid Kava RPC services and managed dedicated nodes for application developers, wallets, exchanges, and analytics teams.

## Service features

- JSON-RPC access for reading blockchain data and submitting transactions.
- gRPC connections for programmatic access to chain data and services.
- RESTful APIs for integrating blockchain data into applications.
- Trace APIs for transaction debugging and execution analysis.
- 101 Dashboard for usage, endpoints, performance, and service status. Available on Business, Expert, and Enterprise plans.
- Distributed request handling across multiple nodes for availability and consistent performance.
- 24/7 technical support from the infrastructure team.
- Incident reports covering the impact, cause, and resolution of service disruptions. Available on Business, Expert, and Enterprise plans.
- Managed node operations, node maintenance, and real-time infrastructure monitoring through monitor101, with traffic and log tracking.
- API key management across shared plans. Technical support is standard on Starter, advanced on Business, and priority on Expert. Business and Expert include advanced and priority incident tracking, respectively.

## Available on request

- Kava testnet RPC is available on request.
- Archive node services for historical blockchain data are available on request.
- Dedicated deployment options in Türkiye, Europe, and the United States. The region and configuration are agreed during onboarding. Türkiye-hosted infrastructure can be scoped for local hosting and regulatory requirements.
- Additional features and custom configurations may increase the price.

Prices exclude taxes. CUPS means compute units per second; monthly quotas count requests. An unlimited monthly quota retains the plan's throughput limit. Response times are published averages, not per-request guarantees.

This is a paid, closed-source service. No free public RPC, free tier, or free trial is offered. To get started, visit the [node101 Kava service page](https://node101.io/en/rpc/kava), select a plan or request dedicated infrastructure, and agree the network, interfaces, and configuration with the team. Endpoint details are supplied through onboarding.

Service availability, maintenance, incident handling, and service credits are governed by the applicable [Service-Level Agreement](https://node101.io/legal/en/service-level-agreement.pdf).

## Get started

1. Visit the [node101 Kava service page](https://node101.io/en/rpc/kava) and select a plan or request dedicated infrastructure.
2. Use the contact form to specify your mainnet or testnet needs, API interfaces, capacity, archive requirements, and deployment region.
3. Agree the commercial terms and configuration with the node101 team, then receive your endpoint and access details.
4. Integrate the endpoint into your application and use the monitoring and support services included in your plan.
